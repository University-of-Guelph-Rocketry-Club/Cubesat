# Independent COTS avionics

MissileWorks RRC-series altimeters and Eggtimer/Eggfinder equipment are independent COTS avionics and tracking/recovery systems. They are not dependencies of the student-built payload computer.

The primary payload computer must be able to boot, collect scientific data, and log onboard data without receiving data from these systems. Any future integration requires an explicitly selected interface, electrical review, protocol documentation, and tests; it must not be assumed by flight firmware.
